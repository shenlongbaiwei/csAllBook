    STL源码剖析-2.1空间配置器的标准接口¶

    STL的规范，注意正常规范的STL的空间配置器是设计在allocator类中的，但是SGI-STL的空间次配置器是alloc。后续还会对alloc进行剖析和学习。

    allocator的一些必要的接口：

    C++
    allocator::value_type;

allocator::reference;//引用

    C语言在内存中一共分为如下几个区域，分别是：

    1. 内存栈区： 存放局部变量名；
    2. 内存堆区： 存放new或者malloc出来的对象；
    3. 常数区： 存放局部变量或者全局变量的值；
    4. 静态区： 用于存放全局变量或者静态变量；
    5. 代码区：二进制代码。 知道如上一些内存分配机制，有助于我们理解指针的概念。

    C/C++不提供垃圾回收机制，因此需要对堆中的数据进行及时销毁，防止内存泄漏，使用free和delete销毁new和malloc申请的堆内存，而栈内存是动态释放。

    new操作符，也可以使用例如new (ptr) int(xx);这样的语法，这样的语法表示在已经分配的空间ptr上进行创建一个对象，并将对象分配到该内存空间上。

    placement new 是用来定位构造的。

    placement new既可以在堆上构造，也可以在栈上构造。

    简单语法：

    ptrdiff_t 是一种在 C 和 C++ 标准库中定义的类型，用于表示两个指针之间的差值。它通常用于指针算术运算和数组索引计算。ptrdiff_t 是一个有符号整数类型，定义在 <cstddef> 头文件中。

    以下是一些关于 ptrdiff_t 的详细信息：

    1. 定义：

    #include

    typedef /* implementation-defined */ ptrdiff_t;

    1. 用途：

    2. 表示两个指针之间的差值。

    3. 用于指针算术运算的结果类型。

    4. 示例：

    #include

    #include

    int main() {

    Text Only
     int arr[] = {1, 2, 3, 4, 5};

 int* p1 = &arr[1];

 int* p2 = &arr[4];

 ptrdiff_t diff = p2 - p1;

 std::cout << "Difference between pointers: " << diff << std::endl;

 return 0;

    }

    在这个示例中，diff 将存储 p2 和 p1 之间的差值，即数组元素的数量。

    ptrdiff_t 的主要优点是它是一个有符号类型，可以表示负的指针差值，这在某些情况下是有用的。

    我这里做的是easy_alloc::allocator

    C++
    #ifndef EASY_ALLOC_H
#define EASY_ALLOC_H
#pragma once
#include <iostream>
#include <new>
#include <cstdlib>
#include<cstdlib>
#include <climits>

namespace easy_alloc{
    template <class T>
    inline T* _allocate(ptrdiff_t size,T*){
        std::set_new_handler(0);
        T* tmp=(T*)(::operator new((size_t)(size*sizeof(T))));
        if(tmp==0){
            std::cerr<<"out of memory"<<std::endl;
            exit(1);
        }
        return tmp;
    }
    template <class T>
    inline void _deallocate(T* buffer){
        ::operator delete(buffer);
    }
    template<class T1,class T2>
    inline void _construct(T1*p,const T2&value){
        new((void*)p) T1(value);
        //这里调用的就是palcement new操作
    }
    template <class T>
    inline void _destroy(T*ptr){
        ptr->~T();
    }
    template <class T>
    class allocator{
        public:
        typedef T value_type;
        typedef T* pointer;
        typedef const T* const_pointer;
        typedef T& reference;
        typedef const T& const_reference;
        typedef size_t size_type;//这个就是类型大小
        typedef ptrdiff_t difference_type;

        //rebind allocator of type U
        template <class U>
        struct rebind{
            typedef allocator<U> other;
        };
        //size_type n表示分配size_type类型数据的个数
        pointer allocate(size_type n,const void*hint=0){
            return _allocate((difference_type)n,(pointer)0);
        }
        void deallocate(pointer p,size_type n){
            _deallocate(p);
        }
        void construct(pointer p,const T& value){
            _construct(p,value);
        }
        void destroy(pointer p){
            _destroy(p);
        }
        pointer address(reference x){
            return (pointer)&x;
        }
        const_pointer const_address(const_reference x){
            return (const_pointer)&x;
        }
        size_type max_size() const{
            return size_type(UINT_MAX/sizeof(T));
        }

    };
}
#endif

}

    上面的h文件中的类，主要是用来简单重载了部分的空间配置器，所以我们直接在vector使用即可，在调用的时候会调用对应的easy_alloc的代码来进行分配空间操作。
