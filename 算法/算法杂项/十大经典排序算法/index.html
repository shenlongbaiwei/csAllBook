    十大经典排序算法¶

    基本的专业术语： 稳定排序：两个值相同的元素，位置不同，在排序后的相对位置不会发生改变 不稳定排序：两个值相同的元素，位置不同，在排序后的相对位置会改变 原地排序：不使用额外的辅助空间，即只需要在本来的空间基础上进行元素排序互换即可 非原地排序：需要定义额外的数组空间，进行相关的排序 时间复杂度：根据实际情况，算法的平均理论时间来看 空间复杂度：同理

    选择排序¶

    思路：

    该算法放在第一个，很明显他的排序思路是极其简单的，因为他既然要排序，那我们正常人的思路就是找先找最小元素放第一个，然后在其他元素中找最小的放第二个，一直循环往下寻找，最后直到最后一个元素，就算结束了。

    这种排序算法因为思路就是每次选一个进行排序，所以我们称为选择排序。

    给定一个无序数组，我们逐渐在循环的过程中，将数组分为有序区间和无序区间。

    有序区间在每次循环的时候数量+1，无序的元素数量减一

    代码：

    C++
    void selectSort(int[]arr){
    for(int i=0;i<arr.length-1;i++){
        int minIndex=i;
        for(j=i+1;j<arr.length-1;j++){
            if(arr[minIndex]>arr[j]){
                minIndex=j;
            }
        }
        swap(arr,minIndex,i);//将最小的元素交换到第i个的位置
    }
}
void swap(int[] arr,int minIndex,int i){
    int z=arr[minIndex];
    arr[minIndex]=arr[i];
    arr[i]=z;
}

    时间复杂度：第一轮执行了n-1次，第二轮执行了n-2次，...第n轮执行了1次

    总的执行次数就是等差数列求和公式。

    总的时间复杂度就是O(n^2);

    对于稳定性，选择元素之后会发生交换操作，所以有可能会把前面的元素换到后面导致与他相等的元素都排他前面了。

    所以选择排序是一个不稳定排序。

    插入排序¶

    其实该算法的思路非常简单。

    思路¶

    1、从第二个元素开始选取

    2、将第二个元素的大小和第一个元素相比，如果比第一个小，那么交换位置，如果比第一个元素大，那么就不变。

    3、此时前两个元素比较完成，那么前两个元素就是一个有序数组，此时总数组中的无序数组元素数量就是n-2个。

    4、继续循环，选择第三个元素，将该元素和有序数组中的元素，从头比较，找到适当的位置插入并将其余元素后移。

    5、一直重复2、3、4等步骤，直到所有元素都位于有序数组。

    代码：

    C++
    public class InsertSort{
    public static int[] insertSort(int[] arr){
        if(arr==null||arr.length<2){
            return arr;
        }
        int n=arr.length;
        for(int i=1;i<n;i++){
            int temp=arr[i];
            int k=i-1;
            while(k>=0&&arr[k]>temp)
                k--;
            for(int j=i;j>k+1;j--){
                arr[j]=arr[j-1];
            }
            arr[k+1]=temp;
        }
        return arr;
    }

}

    上述算法的时间复杂度：O(N^2)，空间复杂度：因为只借用了一个元素空间，所以空间复杂度是O(1)，

    是否是稳定排序：因为在排序过程中，是判断严格大于的，所以在排序过程中，相同元素，前一个元素会先排序，后一个元素会后排序，同时两个元素的前后顺序是不变的。

    是否是原地排序：因为整个排序过程中，所有元素的空间复杂度是O(1)，所以是原地排序。

    冒泡排序¶

    思路：其实该题的思路非常简单，顾名思义，冒泡排序就是将无序的数组，通过像鱼类吐泡泡一样的效果，大的泡泡在上先浮上去，小的后浮。

    C++
    public class BubbleSort{
    public static int[] bubbleSort(int[] arr){
        if(arr==null||arr.length<2){
            return arr;
        }
        int n=arr.length;
        for(int i=0;i<n;i++){
            for(int j=0;j<n-i-1;j++){
                if (arr[j + 1] < arr[j]) {
                    int t = arr[j];
                    arr[j] = arr[j+1];
                    arr[j+1] = t;
                }
            }
        }
        return arr;
    }
}

    冒泡算法优化：

    当比较一轮之后没有找到或者没有发生交换，那么就表明已经有序，我们直接退出循环即可。

    代码：

    C++
    public class BubbleSort {
    public static int[] bubbleSort(int[] arr) {
        if (arr == null || arr.length < 2) {
            return arr;
        }
        int n = arr.length;
        for (int i = 0; i < n; i++) {
            boolean flag = true;
            for (int j = 0; j < n -i - 1; j++) {
                if (arr[j + 1] < arr[j]) {
                    flag = false;
                    int t = arr[j];
                    arr[j] = arr[j+1];
                    arr[j+1] = t;
                }
            }
            //一趟下来是否发生位置交换
            if(false)
                break;
        }
        return arr;
    }
}

    希尔排序¶

    思路

    其实希尔排序就是插入排序的一种变种，无论是插入排序还是冒泡排序，每次循环一趟之后都会得到一个排好序的元素。但是如果最大元素处于数组的两端，容易在排序的过程中浪费较多的交换费用。

    希尔排序是为了加速排序速度，简化插入排序，交换不相邻的元素以对数组的局部进行排序。

    思路很简单，就是开始选择一定间隔的元素作为一组，将数组分为若干组，每个小组排完序之后，将间隔缩小重新分组排序，如果循环，直到间隔为1的时候，此时数组只需要进行简单的微调就可以达到想要的效果。

    通过上述的思路，我们可以加快数组的排序，只不过在实现的过程中我们需要使用直接排序而已。

    代码：

    C++
    #include<iostream>
int[] xierSort(int[] arr){
    int n=arr.length;
    int init_gap=2;
    int arr_nums=n/init_gap;
    while(arr_nums>0){
        for(int i=arr_nums;i<n;i++){
            InsertSort(arr,h,i);
        }
        arr_nums/=2;
    }
    return arr;
}
void InsertSort(int[] arr,int h,int i){
    //h是当前数组间隔
    int temp=arr[i];
    int k;
    for(k=i-h;k>0&&arr[k]>temp;k-=h){
        arr[k+h]=arr[k];
    }
    arr[k+h]=temp;
}

    注意：在上述的xierSort排序的过程中，我们每次局部排序的时候并非是轮流将每个局部数组排完序后再排下一个局部数组，而是每一个局部数组的元素都按顺序进行排序，即所有局部数组可以认为每一轮小循环中都进行了排序，交替执行直接插入排序。

    性质：1、时间复杂度：O(nlogn) 2、空间复杂度：O(1) 3、非稳定排序 4、原地排序

    归并排序¶

    思路

    其实该排序方法的思路和希尔排序的思想有点像，都是将一个大问题分解为若干相似的小问题来进行求解。

    归并排序是初始的时候将数组分为两个数组，分别排序，将需要排序的两个数组再分为四个数组，一直往下分割，直到小数组只有一个元素为止。

    然后再将小的有序数组合并起来排序，这样会快很多。

    代码：

    C++
    void mergeSort(int[]arr,int left,int right){
    if(left<right){
    int mid = (left + right) / 2;
            // 对左半部分进行排序
            arr = mergeSort(arr, left, mid);
            // 对右半部分进行排序
            arr = mergeSort(arr, mid + 1, right);
            //进行合并
            merge(arr, left, mid, right);
        }
        return arr;

}
void merge(int[] arr, int left, int mid, int right){
    int[] a = new int[right - left + 1];
        int i = left;
        int j = mid + 1;
        int k = 0;
        while (i <= mid && j <= right) {
            if (arr[i] < arr[j]) {
                a[k++] = arr[i++];
            } else {
                a[k++] = arr[j++];
            }
        }
    while(i <= mid) a[k++] = arr[i++];
    while(j <= right) a[k++] = arr[j++];
    for (i = 0; i < k; i++) {
            arr[left++] = a[i];
        }
}

    性质：1、时间复杂度：O(nlogn) 2、空间复杂度：O(n) 3、稳定排序 4、非原地排序

    非递归版：

    C++
    public class MergeSort {
    // 非递归式的归并排序
    public static int[] mergeSort(int[] arr) {
        int n = arr.length;
        // 子数组的大小分别为1，2，4，8...
        // 刚开始合并的数组大小是1，接着是2，接着4....
        for (int i = 1; i < n; i += i) {
            //进行数组进行划分
            int left = 0;
            int mid = left + i - 1;
            int right = mid + i;
            //进行合并，对数组大小为 i 的数组进行两两合并
            while (right < n) {
                // 合并函数和递归式的合并函数一样
                merge(arr, left, mid, right);
                left = right + 1;
                mid = left + i - 1;
                right = mid + i;
            }
            // 还有一些被遗漏的数组没合并，千万别忘了
            // 因为不可能每个字数组的大小都刚好为 i
            if (left < n && mid < n) {
                merge(arr, left, mid, n - 1);
            }
        }
        return arr;
    }
}

    快速排序¶

    思路：

    快排的思路还是递归，将大问题分割成好几个小问题，然后分开处理。

    在该算法中，我们开始选择一个元素，将比该元素小的元素放到左边，大的元素放到右边，然后将数组划分为两个数组，然后分别对两个数组执行相同的操作，直到将数组的大小分割为1为止。

    代码：

    C++
    int[] quickSort(int[] arr, int left, int right) {
    if (left < right) {
            //获取中轴元素所处的位置
            int mid = partition(arr, left, right);
            //进行分割
            arr = quickSort(arr, left, mid - 1);
            arr = quickSort(arr, mid + 1, right);
        }
        return arr;
}
int partition(int[] arr, int left, int right) {
        //选取中轴元素
        int pivot = arr[left];
        int i = left + 1;
        int j = right;
        while (true) {
            // 向右找到第一个大于等于 pivot 的元素位置
            while (i <= j && arr[i] <= pivot) i++;
            // 向左找到第一个小于等于 pivot 的元素位置
            while(i <= j && arr[j] >= pivot ) j--;
            if(i >= j)
                break;
            //交换两个元素的位置，使得左边的元素不大于pivot,右边的不小于pivot
            int temp = arr[i];
            arr[i] = arr[j];
            arr[j] = temp;
        }
        arr[left] = arr[j];
        // 使中轴元素处于有序的位置
        arr[j] = pivot;
        return j;
    }

    性质：1、时间复杂度：O(nlogn) 2、空间复杂度：O(logn) 3、非稳定排序 4、原地排序

    堆排序¶

    思路

    堆排序的特点就是堆顶元素是一个最大值或者最小值，大顶堆就是最大值，小顶堆就是最小值。

    堆是具有以下性质的完全二叉树：

    每个结点的值都大于或等于其左右孩子结点的值，称为大顶堆，如果小于等于的话就是小顶堆。

    用简单的公式来描述一下堆的定义就是：

    大顶堆：arr[i] >= arr[2i+1] && arr[i] >= arr[2i+2]

    小顶堆：arr[i] <= arr[2i+1] && arr[i] <= arr[2i+2]

    ok，了解了这些定义。接下来，我们来看看堆排序的基本思想及基本步骤：

    堆排序的基本思想：

    将待排序序列构造成一个大顶堆，那么大顶堆的堆顶就是序列的最大值，此时将堆顶元素和数组序列最右端元素相交换，就可以让n个元素的数组完成一个元素的排序，然后将剩余n-1个元素构造成新的大顶堆，这样求出次最大值，就这样循环往复，最终排序完成。

    在代码实现中，我们使用了与“堆”章节相同的从顶至底堆化 sift_down() 函数。值得注意的是，由于堆的长度会随着提取最大元素而减小，因此我们需要给 sift_down() 函数添加一个长度参数 n ，用于指定堆的当前有效长度。

    代码：

    C++
    void siftDown(vector<int>&nums,int n,int i){
    while(true){
        int l=2*i+1;
        int r=2*i+2;
        int max=i;
        if(l<n&&nums[l]>nums[max]){
            max=l;
        }
        if(r<n&&nums[r]>nums[max]){
            max=r;
        }
        if(max==i){
            break;
        }
        //交换两个节点
        swap(nums[i],nums[max]);
        //堆向下堆化
        i=max;
    }
}
//堆排序
void heapSort(vector<int>&nums){
    //建堆操作
    for(int i=nums.size()/2-1;i>=0;--i){
        siftDown(nums,nums.size(),i);
    }
    //从堆中找最大元素，持续n-1轮循环
    for(int i=nums.size()-1;i>0;--i){
        swap(nums[0],nums[i]);
        siftDown(nums,i,0);
    }
}

    算法特性

    • 时间复杂度为 O(nlog⁡n)、非自适应排序：建堆操作使用 O(n) 时间。从堆中提取最大元素的时间复杂度为 O(log⁡n) ，共循环 n−1 轮。
    • 空间复杂度为 O(1)、原地排序：几个指针变量使用 O(1) 空间。元素交换和堆化操作都是在原数组上进行的。
    • 非稳定排序：在交换堆顶元素和堆底元素时，相等元素的相对位置可能发生变化。
    • 堆排序也算是一种选择排序

    计数排序¶

    思路：

    通过统计元素数量来实现排序，通常用于整数数组。

    步骤：

    1、遍历寻找当前数组最大元素

    2、构造一个当前最大元素大小+1的counter数组

    3、统计nums数组中的所有元素各自出现次数

    4、统计完成之后，这些元素各自天然有序，此时将counter的元素依次放入nums中即可。

    代码：

    C++
    void countingSort(vector<int>&nums){
    //1统计最大元素
    int m=0;
    for(int num:nums){
        //if(num>m){
          //  m=num;
        //}
        m=max(m,num);
    }
    //2统计各个元素的出现次数
    vector<int> counter(m+1,0);
    for(int num:nums){
        counter[num]++;
    }
    //3将counter的元素填入nums
    int i=0;
    for(int num=0;num<m+1;num++){
        for(int j=0;j<counter[num];j++){
            nums[i]=num;
            i++;
        }
    }
}

    从桶排序的角度看，我们可以将计数排序中的计数数组 counter 的每个索引视为一个桶，将统计数量的过程看作将各个元素分配到对应的桶中。本质上，计数排序是桶排序在整型数据下的一个特例。--hello算法

    桶排序¶

    桶排序，顾名思义，通过设置一些具有大小顺序的桶，每个桶对应有一个数据范围，将数据平均分配到各个桶中；

    然后在每个桶中分别执行排序，最后将所有桶中元素合并即可。

    代码：

    C++
    void bucketSort(vector<float>&nums){
    int k=nums.size()/2;
    vector<vector<float>> buckets(k);
    for(float num:nums){
        int i=num*k;
        buckets[i].push_back(num);
    }
    //2排序每个桶内元素
    for(vector<float> &bucket:buckets){
        sort(bucket.begin(),bucket.end());
    }
    //3合并桶的结果
    int i=0;
    for(vector<float>&bucket:buckets){
        for(float num:bucket){
            nums[i++]=num;
        }
    }
}

    基数排序¶

    思路： 思路和前面的计数排序差不多，都是通过统计个数来实现排序。

    基数排序还能处理非常大的排序要求的情况。

    主要是通过各个数字的各个位的大小来比较的。

    代码：

    C++
    int digit(int num, int exp) {
    // 传入 exp 而非 k 可以避免在此重复执行昂贵的次方计算
    return (num / exp) % 10;
}


void countingSortDigit(vector<int> &nums, int exp) {
    // 十进制的位范围为 0~9 ，因此需要长度为 10 的桶数组
    vector<int> counter(10, 0);
    int n = nums.size();
    // 统计 0~9 各数字的出现次数
    for (int i = 0; i < n; i++) {
        int d = digit(nums[i], exp); // 获取 nums[i] 第 k 位，记为 d
        counter[d]++;                // 统计数字 d 的出现次数
    }
    // 这一步其实就是将counter的每一位数量加上前面所有比他小的元素数量，从而在后面循环的时候，倒序遍历，每
    // 次判断一个元素，然后该元素对应的索引应该对应于当前统计的counter[i]数组的最后位置，然后将索引减一，因
    // 此我们需要求解这一步循环
    for (int i = 1; i < 10; i++) {
        counter[i] += counter[i - 1];
    }
    // 倒序遍历，根据桶内统计结果，将各元素填入 res
    vector<int> res(n, 0);
    for (int i = n - 1; i >= 0; i--) {
        int d = digit(nums[i], exp);
        int j = counter[d] - 1; // 获取 d 在数组中的索引 j
        res[j] = nums[i];       // 将当前元素填入索引 j
        counter[d]--;           // 将 d 的数量减 1
    }
    // 使用结果覆盖原数组 nums
    for (int i = 0; i < n; i++)
        nums[i] = res[i];
}

/* 基数排序 */
void radixSort(vector<int> &nums) {
    // 获取数组的最大元素，用于判断最大位数
    int m = *max_element(nums.begin(), nums.end());
    // 按照从低位到高位的顺序遍历
    for (int exp = 1; exp <= m; exp *= 10)
        // 对数组元素的第 k 位执行计数排序
        // k = 1 -> exp = 1
        // k = 2 -> exp = 10
        // 即 exp = 10^(k-1)
        countingSortDigit(nums, exp);
}

    因为我们在连续的排序中，后一轮排序会覆盖前一轮排序的结果，而且在数字中，高位的优先级要更高，因此理应放在后面排序，所以我们要从低位向高位排序。
